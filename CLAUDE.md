# snapdash

## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues on `schizza/snapdash`, managed via the `gh` CLI.
See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map onto this repo's existing label vocabulary: `discussion`, `needs-info`, `ready`, `help-wanted`, `wontfix`.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo - one `CONTEXT.md` plus `docs/adr/` at the repo root.
See `docs/agents/domain.md`.
